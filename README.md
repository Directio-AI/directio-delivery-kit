# Directio Delivery Kit

_Versión en inglés: [README.en.md](README.en.md)._

La base compartida que Directio usa para implementar IA en los procesos de sus clientes: instrucciones para agentes, documentos fuente de verdad, plantillas, controles de CI y la estructura base de cada cliente.

Empieza por [AGENTS.md](AGENTS.md). Es el archivo de instrucciones principal para cualquier agente de programación (Claude, Codex, Copilot u otros) y para las personas que trabajan en este repositorio.

**Idioma:** español primero, inglés segundo. Ver la regla 10 de `AGENTS.md`.
