# Directio Delivery Kit

_English version of [README.md](README.md)._

The shared backbone Directio uses to deploy AI into client processes: agent instructions, source-of-truth docs, artifact templates, CI gates and the per-client scaffold.

Start with [AGENTS.md](AGENTS.md) (Spanish original) or [AGENTS.en.md](AGENTS.en.md). It is the canonical instruction file for any coding agent (Claude, Codex, Copilot or others) and for humans working in this repo.
